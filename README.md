# 在线医疗服务平台
> 一站式在线预约挂号平台，支持微信小程序 + Web 管理端，解决挂号难、就诊繁问题，具备高并发、高可用、安全认证等企业级特性。

---

## ✨ 项目亮点
1. **高并发抢号架构**
   - Redis 缓存医生排班与号源信息，大幅降低数据库压力，解决了挂号超号问题
   - 号源扣减采用**乐观锁与事务**，彻底解决高并发下超卖、数据脏写问题
   

2. **全流程业务闭环**
   覆盖：用户注册 → 实名认证 → 就诊卡管理 → 医生排班 → 预约挂号 → 在线支付 → 人脸识别核验 全链路。

3. **企业级权限体系**
   - 基于 SaToken + Redis 实现登录状态管理
   - 自研 RBAC 细粒度权限模型，支持管理员/医生/护士多角色隔离

4. **第三方生态集成**
   - 微信小程序 SDK、微信支付 SDK 对接
   - 腾讯云 OCR 身份证识别 + 人脸识别实名认证
   - MinIO 对象存储存储医生头像、医疗图片

5. **容器化部署**
   项目基于 Docker 容器化打包，将本地项目打包成Jar文件，上传至容器的挂载目录，并启动项目。
   Nginx 反向代理，可快速上云部署。
   
6.**LinkedHashMap & TreeMap的使用**
  在查询医生问诊日程接口开发中，为保证医生的出诊记录按日期排序，使用 LinkedHashMap 与 TreeMap 保障了出诊记录查询的有序性 ，而不是简单的Hashmap。

7.**挂号超时问题解决方案**
  为解决早高峰挂号时的**超时号源预约**，我采用了 Redis 缓存+自动过期机制：
  基于 Redis 过期时间机制，实现号源的自动失效控制，彻底解决了预约挂号场景下的 “超时号源” 问题。
---

## 🛠️ 技术栈
- 后端：Spring Boot、MyBatis、Spring MVC
- 数据库：MySQL 8.0、Redis（缓存+分布式会话）
- 权限：SaToken、RBAC
- 中间件：MinIO、Nginx
- 部署：Docker
- 第三方：微信小程序 SDK、微信支付、腾讯云 OCR / 人脸识别
- 前端：Vue2、ElementUI、微信小程序
